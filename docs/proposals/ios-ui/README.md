# iOS UI wireframes

Read with the [UI specification](../ios-ui.md). All frames are 390 × 844,
self-contained SVG shapes and text. Frames 01–16 use existing Catppuccin Latte
tokens; 17–19 use Catppuccin Mocha. Content is illustrative; camera, keyboard
and Face ID areas are schematic. Full screens and sheets use the same canvas;
longer content scrolls as specified. Frame 08 shows a choice already selected by
the user; the initial review has no selection.

1. [Pair a host](01-pairing-scan.svg) — First run, scanner and paste-link alternative.
2. [Compare codes](02-pairing-code.svg) — Host identity context and six-digit comparison.
3. [Host approval](03-pairing-approval.svg) — Wait for the host to approve Observe access.
4. [Paired](04-paired.svg) — Pairing success, actual scope and next actions.
5. [Hosts](05-hosts.svg) — Local host records and the selected connection.
6. [Projects and places](06-places.svg) — Working, waiting, finished and inactive places.
7. [Place detail](07-place-detail.svg) — Waiting card, agent/model, provenance and brief.
8. [Answer review](08-answer-review.svg) — Full sample prompt, selected choice and confirmation.
9. [Face ID](09-face-id.svg) — Schematic iOS authentication with target context.
10. [Prompt changed](10-prompt-changed.svg) — Stale-choice refusal and fresh review path.
11. [Message composer](11-message-composer.svg) — Explicit send, validation and keyboard area.
12. [Recent turns](12-recent-turns.svg) — Read-only exchanges with tool-name summaries.
13. [This device](13-device-settings.svg) — Effective capabilities, expiry, revoke and forget.
14. [Offline](14-offline.svg) — Persistent connection state, last-known data and retry.
15. [Start session](15-start-session.svg) — Agent/model selection in an existing place.
16. [Place metadata](16-place-metadata.svg) — Shared note, pin and lifecycle editing.
17. [Places, dark](17-places-dark.svg) — Mocha rendering of frame 06.
18. [Place detail, dark](18-place-detail-dark.svg) — Mocha rendering of frame 07.
19. [Answer review, dark](19-answer-review-dark.svg) — Mocha rendering of frame 08.
